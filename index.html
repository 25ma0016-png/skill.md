Abstract

Stop words are high-frequency function words such as pronouns, postpositions and auxiliaries that are routinely removed before text is analysed. Hindi is written by hundreds of millions of people, yet it is also typed daily in Latin script on phones, social media and chat. This project assembles a curated list of 0 unique Romanized Hindi stop words, organises them into ten linguistically motivated categories, and analyses how they are distributed by category, word length and initial letter. The list is shipped as a reusable Python module (hindi_stopwords.py) with a small removal function and presented on this interactive page.

2

Objective

  • Compile a clean, de-duplicated Hindi stop-word list for text pre-processing.
  • Classify every word by its grammatical function.
  • Quantify the structure of the list with simple visual analysis.
  • Package the result as a documented Python file and a public web page.
3

Research Question

Which grammatical classes make up Hindi stop words, and how are they distributed in a Romanized word list used for NLP pre-processing?

Sub-questions: Which category is the largest? How long are the words? Does Romanization produce spelling variants (nahi / nahin, mai / main)?

4

Methodology

CollectA seed list of about 200 common Hindi function words was written in Latin script.
CleanDuplicates (liye, yahi, waise) were removed while keeping order, leaving unique entries.
CategoriseEach word was assigned to exactly one grammatical category; a script check confirms full coverage.
AnalyseCounts, length distribution and initial letters were computed directly from the list.
PublishDelivered as hindi_stopwords.py, pushed to GitHub, and shown on this page.

Discussion

Romanization brings spelling variation: nahi/nahin, mai/main, hum/ham, poora/pura all appear, so a practical list must include variants. Some words are ambiguous: par can be a postposition or a conjunction, and kam can be a quantifier or a noun, which is why each word was given its dominant function.

8

Limitation

  • The list is Romanized; it does not include Devanagari forms.
  • It is a sample list and was not derived from a frequency study of a large corpus.
  • Each word has one category, though some are multi-functional.
  • Removal is word-based, so multi-word entries such as har ek need phrase handling.
